# Automated E-Waste Management System

## Project Overview
The Automated E-Waste Management System is a Python-based console application designed to manage electronic waste items efficiently. It helps users record, search, update, and delete e-waste details while monitoring storage capacity and generating reports.

## Features
- Add new e-waste items
- View all stored items
- Search items by ID or name
- Update item details
- Delete items
- Monitor storage capacity
- Calculate storage fees with discounts
- Generate summary reports

## Technologies Used
- Python

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code or another Python IDE.
3. Run the following command:

```bash
python FP.py
```
